title: Installation für Administratoren
description: BSBox in Ihrer Organisation bereitstellen.
---

## Microsoft 365 Admin Center (Outlook)

1. Im Microsoft 365 Admin Center als globaler oder Exchange-Administrator anmelden.
2. **Einstellungen > Integrierte Apps > Benutzerdefinierte Apps hochladen** öffnen.
3. **Office-Add-In** wählen und das BSBox-Manifest hochladen.
4. Benutzern oder Gruppen zuweisen und bestätigen.

## Benutzerdefinierte Teams-App

1. Im Teams Admin Center **Teams-Apps > Apps verwalten** öffnen.
2. **Neue App hochladen** wählen und das BSBox-App-Paket hochladen.
3. In den **Setuprichtlinien** die App für die vorgesehenen Benutzer erlauben.

Änderungen können bis zu 24 Stunden dauern. Probleme? Siehe [Support](/de/support/) und [Sicherheit](/de/security/).
