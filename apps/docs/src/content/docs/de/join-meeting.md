---
title: An einem Meeting teilnehmen
description: So treten Teilnehmende bei und geben ihr Engagement an.
---

1. Link aus der Einladung öffnen oder den QR-Code scannen.
2. **Ich spreche** oder **Das ist interessant** antippen. Erneutes Antippen einer aktiven Karte hebt sie auf. Der letzte Zustand innerhalb einer Minute zählt.
3. Jederzeit verlassen. Das Schließen der Seite ist in Ordnung.

Sie bleiben anonym. BSBox speichert ein zufälliges Token in Ihrem Browser, nie Name oder E-Mail. Siehe [Datenschutz](/de/privacy/).
